# Mr. Fix It All Repair Services — Website V3

Official website source for the approved V3 design: bold blue-and-black appliance repair artwork, service-request form, About Us, dryer-cleaning information, specials, and a searchable Appliance Resources Q&A.

## Website

Expected GitHub Pages URL after publication: https://james7477.github.io/mr-fix-it-all/

This repository includes a **standalone `index.html`** with all the artwork, styling, and scripts embedded. It can be hosted directly as a static site. No database or paid hosting is required.

## One-time GitHub Pages setup

1. Visit https://github.com/James7477/mr-fix-it-all/settings/pages in a web browser.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then tap **Save**.
4. Return to the Pages Settings screen for the confirmed live URL and deployment status.

## Important notes

- The scheduling form opens a prepared SMS request; it does not automatically send a message or confirm an appointment.
- The Q&A section contains general appliance advice and allows visitors to text questions.
- Verify the pricing and offer conditions and obtain the business owner's approval to publish the advertised name, artwork, phone number, and services.
